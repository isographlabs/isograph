# resolve_position: no-hit arm via `From` into `ResolvedNode`

A struct’s no-hit arm can return `self.path(parent).to()` or `parent.to()` as `ResolvedNode`, instead of `ResolvedNode::#struct_name(...)`. The `From` impl chooses the variant. generic-slot.md uses this.

This is a struct attribute, not a field attribute. A field that misses does not return; it is not a leaf. Field attributes already name how a hit builds the child’s parent (`#[parent_from]`, `#[parent_variant]`, `#[resolve_field(transparent)]`). The no-hit arm is the struct’s leftover after every field has declined.

There is no `From<Path<&T, T::Parent>> for IsographResolutionNode` today, and none from `enum IsographResolutionNode { EntrypointDeclaration(EntrypointDeclarationPath) }`. The derive writes the variant name from the struct name. Conversion on the path is only path → payload, usually identity.

Before:

```rust
// from crates/resolve_position_macros/src/resolve_position_macro.rs
        quote! {
            return Self::ResolvedNode::#struct_name(self.path(parent).to());
        }
```

```rust
// generated by resolve_position_macros/src/resolve_position_macro.rs
            return Self::ResolvedNode::EntrypointDeclaration(self.path(parent).to());
```

## After

```rust
// from crates/resolve_position_macros/src/resolve_position_macro.rs
struct ResolvePositionArgs {
    parent_type: syn::Type,
    resolved_node: syn::Type,
    self_type_generics: Option<syn::AngleBracketedGenericArguments>,
    fallback: Option<syn::Ident>,
}
```

`fallback = from_path` emits `return self.path(parent).to();`. `fallback = from_parent` emits `return parent.to();`. Absent, the emit stays `Self::ResolvedNode::#struct_name(self.path(parent).to())`. Any other ident is a compile error. `handle_data_enum` binds `fallback` and errors if it is `Some`: enums have no container fallback. `transparent` still suppresses fallback entirely.

```rust
// from crates/resolve_position_macros/src/resolve_position_macro.rs
    let ResolvePositionArgs {
        parent_type,
        resolved_node,
        self_type_generics,
        fallback,
    } = resolve_position_args;
```

```rust
// from crates/resolve_position_macros/src/resolve_position_macro.rs
    let fallback = if field_infos
        .iter()
        .any(|info| matches!(info.field_type, ResolveFieldInfoTypeWrapper::Transparent(_)))
    {
        quote!()
    } else if fallback.as_ref().is_some_and(|ident| ident == "from_path") {
        quote! {
            return self.path(parent).to();
        }
    } else if fallback.as_ref().is_some_and(|ident| ident == "from_parent") {
        quote! {
            return parent.to();
        }
    } else {
        quote! {
            return Self::ResolvedNode::#struct_name(self.path(parent).to());
        }
    };
```

`from_path` needs `ResolvedNode: From<PositionResolutionPath<&Self, Parent>>` on the type. `from_parent` needs `ResolvedNode: From<Parent>`. The impls are written at the monomorph, not in the derive.

## Tests

```rust
// from crates/resolve_position_macros/tests/fallback_from.rs
use prelude::Postfix;
use resolve_position::{PositionResolutionPath, ResolvePosition};
use resolve_position_macros::ResolvePosition;
use span::{Span, WithSpan, WithSpanPostfix};

#[derive(Debug)]
enum TestResolvedNode<'a> {
    List(ParentPath<'a>),
    Slot(PositionResolutionPath<&'a Slot<Child>, ParentPath<'a>>),
    Child(ChildPath<'a>),
}

type ParentPath<'a> = PositionResolutionPath<&'a List, ()>;

type ChildPath<'a> = PositionResolutionPath<&'a Child, ParentPath<'a>>;

impl<'a> From<PositionResolutionPath<&'a Slot<Child>, ParentPath<'a>>> for TestResolvedNode<'a> {
    fn from(path: PositionResolutionPath<&'a Slot<Child>, ParentPath<'a>>) -> Self {
        TestResolvedNode::Slot(path)
    }
}

impl<'a> From<ParentPath<'a>> for TestResolvedNode<'a> {
    fn from(path: ParentPath<'a>) -> Self {
        TestResolvedNode::List(path)
    }
}

#[derive(Debug, ResolvePosition)]
#[resolve_position(parent_type = (), resolved_node = TestResolvedNode<'a>)]
struct List(#[resolve_field] Vec<WithSpan<Slot<Child>>>);

#[derive(Debug, ResolvePosition)]
#[resolve_position(
    parent_type = ParentPath<'a>,
    resolved_node = TestResolvedNode<'a>,
    fallback = from_path
)]
struct Slot<T: ResolvePosition>
where
    for<'a> T: ResolvePosition<ResolvedNode<'a> = TestResolvedNode<'a>>,
    for<'a> TestResolvedNode<'a>:
        From<PositionResolutionPath<&'a Slot<T>, <T as ResolvePosition>::Parent<'a>>>,
{
    #[resolve_field]
    item: Option<WithSpan<T>>,
}

#[derive(Debug, ResolvePosition)]
#[resolve_position(parent_type = ParentPath<'a>, resolved_node = TestResolvedNode<'a>)]
struct Child;

#[derive(Debug, ResolvePosition)]
#[resolve_position(
    parent_type = ParentPath<'a>,
    resolved_node = TestResolvedNode<'a>,
    fallback = from_parent
)]
struct Wrapper {
    #[resolve_field]
    item: Option<WithSpan<Child>>,
}

#[test]
fn from_path_gap_uses_the_from_impl() {
    let list = List(
        Slot::<Child> {
            item: Child.with_span(Span::new(0, 2)).wrap_some(),
        }
        .with_span(Span::new(0, 8))
        .wrap_vec(),
    );

    match list.resolve((), Span::new(4, 5)) {
        TestResolvedNode::Slot(path) => {
            assert!(path.inner.item.is_some());
        }
        node => panic!("expected the slot, got {node:?}"),
    }
}

#[test]
fn from_path_hit_still_descends() {
    let list = List(
        Slot::<Child> {
            item: Child.with_span(Span::new(0, 4)).wrap_some(),
        }
        .with_span(Span::new(0, 4))
        .wrap_vec(),
    );

    match list.resolve((), Span::new(1, 2)) {
        TestResolvedNode::Child(_) => {}
        node => panic!("expected the child, got {node:?}"),
    }
}

#[test]
fn from_parent_gap_uses_the_from_impl() {
    let list = List(vec![]);
    let wrapper = Wrapper {
        item: Child.with_span(Span::new(0, 2)).wrap_some(),
    };

    match wrapper.resolve(list.path(()), Span::new(4, 5)) {
        TestResolvedNode::List(path) => {
            assert!(std::ptr::eq(path.inner, list.reference()));
        }
        node => panic!("expected the list, got {node:?}"),
    }
}
```
